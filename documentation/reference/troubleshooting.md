## 👥 Проблемы пользователей

### 🔴 Проблема: Бот не отвечает на команду `/start`

**Симптомы:**
- Бот не присылает приветственное сообщение
- Нет реакции на команду `/start`
- Зависание интерфейса

**Возможные причины:**
1. Бот временно недоступен
2. Проблемы с подключением к Telegram API
3. Превышены лимиты Telegram Bot API
4. Проблемы с базой данных

**Решение:**
1. **Подождите 1-2 минуты** и попробуйте снова
2. **Проверьте статус системы** через `/help` команду
3. **Перезапустите диалог** с ботом (удалите чат и начните заново)
4. **Обратитесь к администратору** если проблема повторяется

**Проверка:**
```bash
# Проверка health endpoint
curl http://localhost:3001/health
```

### 🔴 Проблема: Не удается записаться на игру

**Симптомы:**
- Кнопка "Записаться" неактивна
- Ошибка "Игра недоступна"
- Сообщение о превышении вместимости

**Возможные причины:**
1. Игра уже заполнена
2. Запись на игру закрыта организатором
3. Уровень игры не соответствует уровню игрока
4. Игра отменена

**Решение:**
1. **Проверьте статус игры** - откройте информацию об игре
2. **Убедитесь, что уровень игры подходит** вашему уровню
3. **Попробуйте другую игру** с доступными местами
4. **Обратитесь к организатору** для получения информации

**Проверка уровня:**
- Ваш уровень: `/my` → Профиль
- Уровень игры: список игр → информация об игре

### 🔴 Проблема: Не могу отменить запись на игру

**Симптомы:**
- Кнопка "Отменить" не работает
- Ошибка при отмене регистрации
- Запись остается активной

**Возможные причины:**
1. Игра уже началась (менее чем 2 часа до начала)
2. Проблемы с базой данных
3. Ошибка валидации данных

**Решение:**
1. **Проверьте время игры** - отмена возможна за 2+ часа до начала
2. **Попробуйте команду `/leave <game_id>`** вместо кнопки
3. **Обратитесь к организатору** для ручной отмены
4. **Проверьте логи системы** если проблема повторяется

### 🔴 Проблема: Не могу отметить оплату

**Симптомы:**
- Кнопка "Оплатил" неактивна
- Сообщение "Окно оплаты еще не открыто"
- Ошибка при отметке оплаты

**Возможные причины:**
1. Игра еще не началась
2. Прошло слишком много времени после игры
3. Регистрация отменена

**Решение:**
1. **Дождитесь начала игры** - оплата доступна только после старта
2. **Проверьте статус регистрации** в разделе "Мои игры"
3. **Обратитесь к организатору** если прошло более 24 часов

### 🔴 Проблема: Не приходят уведомления

**Симптомы:**
- Отсутствуют напоминания о играх
- Нет уведомлений об изменениях в играх
- Системные сообщения не доставляются

**Возможные причины:**
1. Отключены уведомления в настройках пользователя
2. Блокировка уведомлений в Telegram
3. Проблемы с планировщиком задач
4. Превышены лимиты Telegram API

**Решение:**
1. **Проверьте настройки уведомлений** в профиле
2. **Разрешите уведомления** для бота в Telegram
3. **Проверьте, не заблокирован ли бот**
4. **Обратитесь к администратору** если проблема системная

## 👑 Проблемы организаторов

### 🔴 Проблема: Не удается создать игру

**Симптомы:**
- Мастер создания игры зависает
- Ошибки при выборе даты/времени
- Не сохраняются параметры игры

**Возможные причины:**
1. Неправильный формат даты или времени
2. Указанная дата в прошлом
3. Проблемы с правами доступа
4. Ошибки валидации данных

**Решение:**
1. **Проверьте формат ввода** даты и времени
2. **Убедитесь, что дата в будущем**
3. **Проверьте права доступа** к функциям организатора
4. **Перезапустите создание игры** сначала

**Правильные форматы:**
- Дата: DD.MM.YYYY (например, 25.11.2025)
- Время: HH:MM (например, 19:00)
- Вместимость: число от 6 до 24

### 🔴 Проблема: Игроки не могут записаться на игру

**Симптомы:**
- Список игроков пустой
- Жалобы игроков на недоступность записи
- Ошибки в логах системы

**Возможные причины:**
1. Игра создана с ошибками в параметрах
2. Неправильные настройки доступа
3. Проблемы с базой данных
4. Ошибки в бизнес-логике

**Решение:**
1. **Проверьте параметры игры** через `/mygames`
2. **Убедитесь, что игра открыта** для записи
3. **Проверьте логи системы** на наличие ошибок
4. **Пересоздайте игру** если проблема критична

### 🔴 Проблема: Проблемы с управлением игроками

**Симптомы:**
- Не работают кнопки подтверждения/отклонения
- Ошибки при изменении статуса игрока
- Не сохраняются изменения

**Возможные причины:**
1. Проблемы с правами доступа к игре
2. Игрок уже подтвержден или отклонен
3. Ошибки в обработке callback-запросов
4. Проблемы с базой данных

**Решение:**
1. **Проверьте, что вы являетесь организатором** этой игры
2. **Обновите страницу** списка игроков
3. **Используйте команды** `/confirm` и `/reject` вместо кнопок
4. **Обратитесь к разработчикам** если проблема повторяется

### 🔴 Проблема: Неточная статистика оплат

**Симптомы:**
- Несоответствие количества оплативших
- Отсутствуют данные об оплатах
- Ошибки в расчетах

**Возможные причины:**
1. Игроки не отмечают оплату
2. Проблемы с синхронизацией данных
3. Ошибки в запросах к базе данных
4. Кэширование устаревших данных

**Решение:**
1. **Напомните игрокам** об отметке оплаты
2. **Проверьте актуальность данных** через `/payments`
3. **Очистите кэш** системы
4. **Проверьте логи платежной системы**

## 🔧 Технические проблемы

### 🔴 Проблема: Ошибки подключения к базе данных

**Симптомы:**
- Сообщения "Database connection failed"
- Медленная работа системы
- Потеря данных при сохранении

**Диагностика:**
```bash
# Проверка подключения к PostgreSQL
psql -h localhost -U vball_user -d vball_db

# Проверка статуса PostgreSQL
sudo systemctl status postgresql

# Проверка использования памяти
free -h
```

**Решение:**
1. **Проверьте настройки подключения** в `.env` файле
2. **Перезапустите PostgreSQL** сервис
3. **Проверьте доступное место** на диске
4. **Оптимизируйте запросы** к базе данных

### 🔴 Проблема: Превышение лимитов Telegram API

**Симптомы:**
- Ошибки "Too Many Requests"
- Задержки в доставке сообщений
- Периодические сбои в работе бота

**Диагностика:**
```bash
# Проверка логов на предмет ошибок API
tail -f logs/application.log | grep "429\|Too Many Requests"

# Мониторинг частоты запросов
grep "Telegram API call" logs/application.log | wc -l
```

**Решение:**
1. **Добавьте задержки** между API вызовами
2. **Реализуйте очередь** для сообщений
3. **Оптимизируйте количество** одновременных операций
4. **Используйте Webhook** вместо polling

### 🔴 Проблема: Утечки памяти

**Симптомы:**
- Постепенное увеличение использования памяти
- Замедление работы системы
- Периодические перезапуски приложения

**Диагностика:**
```bash
# Мониторинг использования памяти
top -p $(pgrep node)

# Анализ heap дампа
node --inspect app.js
# В Chrome DevTools: Memory → Take Snapshot

# Проверка утечек в логах
grep "memory leak\|heap\|garbage" logs/application.log
```

**Решение:**
1. **Профилируйте код** на предмет утечек памяти
2. **Добавьте принудительную сборку мусора**
3. **Перезапускайте приложение** по расписанию
4. **Оптимизируйте хранение данных** в памяти

## ⚡ Проблемы производительности

### 🔴 Проблема: Медленная обработка команд

**Симптомы:**
- Команды выполняются более 5 секунд
- Таймауты при выполнении операций
- Жалобы пользователей на скорость

**Диагностика:**
```bash
# Профилирование времени выполнения
node --prof app.js
node --prof-process isolate-*.log > profile.txt

# Анализ медленных запросов
SELECT query, mean_time, calls 
FROM pg_stat_statements 
ORDER BY mean_time DESC 
LIMIT 10;

# Мониторинг производительности API
curl -w "@curl-format.txt" -o /dev/null -s http://localhost:3001/health
```

**Решение:**
1. **Оптимизируйте запросы** к базе данных
2. **Добавьте индексы** на часто используемые поля
3. **Реализуйте кэширование** часто запрашиваемых данных
4. **Используйте connection pooling** для базы данных

### 🔴 Проблема: Высокое использование CPU

**Симптомы:**
- Постоянная загрузка процессора более 80%
- Замедление всех операций
- Перегрев сервера

**Диагностика:**
```bash
# Анализ процессов
top -c
htop

# Профилирование Node.js приложения
node --cpu-prof app.js

# Проверка бесконечных циклов
strace -c -p $(pgrep node)
```

**Решение:**
1. **Найдите и оптимизируйте** CPU-интенсивные операции
2. **Добавьте rate limiting** для API
3. **Используйте worker threads** для тяжелых задач
4. **Масштабируйте горизонтально** при необходимости

## 🔗 Проблемы интеграции

### 🔴 Проблема: Сбои в интеграции с Telegram

**Симптомы:**
- Сообщения не доставляются пользователям
- Ошибки webhook'ов
- Потеря связи с Telegram API

**Диагностика:**
```bash
# Проверка webhook статуса
curl https://api.telegram.org/bot<BOT_TOKEN>/getWebhookInfo

# Тестирование отправки сообщения
curl -X POST "https://api.telegram.org/bot<BOT_TOKEN>/sendMessage" \
     -d "chat_id=<CHAT_ID>" \
     -d "text=Test message"

# Проверка логов webhook
tail -f logs/webhook.log
```

**Решение:**
1. **Проверьте корректность** BOT_TOKEN
2. **Обновите webhook URL** при смене домена
3. **Проверьте настройки firewall** для входящих запросов
4. **Перезарегистрируйте webhook** если необходимо

### 🔴 Проблема: Проблемы с Redis

**Симптомы:**
- Ошибки кэширования
- Потеря запланированных задач
- Замедление работы планировщика

**Диагностика:**
```bash
# Проверка статуса Redis
redis-cli ping

# Мониторинг использования памяти Redis
redis-cli info memory

# Проверка очередей
redis-cli llen bull:queue:notifications
```

**Решение:**
1. **Перезапустите Redis** сервис
2. **Увеличьте лимиты памяти** если необходимо
3. **Очистите устаревшие данные** из кэша
4. **Настройте persistence** для критичных данных

## 🔍 Диагностика и мониторинг

### 📊 Система мониторинга

**Ключевые метрики для отслеживания:**

#### Производительность
- Время отклика API endpoints
- Использование CPU и памяти
- Количество активных пользователей
- Частота ошибок по типам

#### Доступность
- Uptime системы
- Время отклика внешних API
- Количество неудачных операций
- Время простоя по компонентам

#### Бизнес-метрики
- Количество созданных игр в день
- Средняя заполняемость игр
- Процент отмен регистраций
- Активность пользователей

### 📋 Чек-лист диагностики

#### При сбоях системы
1. ✅ Проверьте статус всех сервисов
2. ✅ Проанализируйте логи на предмет ошибок
3. ✅ Проверьте использование ресурсов
4. ✅ Убедитесь в доступности внешних API
5. ✅ Проверьте сетевое подключение

#### При проблемах производительности
1. ✅ Проанализируйте время выполнения операций
2. ✅ Проверьте нагрузку на базу данных
3. ✅ Оцените эффективность запросов
4. ✅ Проверьте размер кэшей
5. ✅ Оптимизируйте алгоритмы при необходимости

#### При проблемах пользователей
1. ✅ Проверьте логи на предмет ошибок валидации
2. ✅ Убедитесь в корректности бизнес-правил
3. ✅ Проверьте настройки прав доступа
4. ✅ Протестируйте воспроизведение проблемы

### 🛠️ Инструменты диагностики

#### Логирование
```bash
# Просмотр логов приложения
tail -f logs/application.log

# Фильтрация по уровню ошибок
grep "ERROR" logs/application.log

# Анализ производительности
grep "response_time" logs/application.log | awk '{print $NF}'
```

#### Мониторинг базы данных
```sql
-- Проверка активных подключений
SELECT count(*) FROM pg_stat_activity;

-- Анализ медленных запросов
SELECT query, mean_time, calls 
FROM pg_stat_statements 
ORDER BY mean_time DESC 
LIMIT 10;

-- Проверка размера таблиц
SELECT 
    schemaname,
    tablename,
    attname,
    n_distinct,
    correlation
FROM pg_stats 
WHERE schemaname = 'public';
```

#### Мониторинг системы
```bash
# Использование ресурсов
df -h              # Дисковое пространство
free -h           # Использование памяти
top -n 1 -b      # Процессы и CPU

# Сетевые подключения
netstat -tuln    # Открытые порты
ss -tuln         # Альтернатива netstat

# Журналы системы
journalctl -u vball-aggregator.service
```
