# Продукт: назначение и возможности

**Назначение:** одно место, где описано, *что* делает VBallAgregator для пользователей, с разбивкой по ролям, видам спорта и зрелости функций. Детальное видение — в [product-vision.md](product-vision.md). Пошаговые сценарии — в [user-scenarios.md](user-scenarios.md). Требования — в [requirements.md](requirements.md). Инструкции для конечного пользователя — в [../guides/user-guide.md](../guides/user-guide.md).

---

## Кратко о продукте

VBallAgregator — **мульти-спорт** Telegram-сервис и backend для **поиска и организации** спортивных событий. Первые виды спорта в каталоге: **волейбол** и **большой теннис**. Ценность для игроков — подходящие игры по уровню и расписанию; для организаторов и площадок — структурированный спрос и рутина записей/оплат/уведомлений.

---

## Роли

| Роль | Описание |
|------|----------|
| **Игрок** | Онбординг по видам спорта, запись на игры (волейбол — основной поток), оплаты, приглашения, `/my` и др. |
| **Организатор** | Создание игр, закрытие, напоминания об оплате, работа с игроками. Для волейбола намерение «организовать» задаётся флагом при онбординге; запись `Organizer` создаётся после завершения полной регистрации, если пользователь выбрал «да». |

Один пользователь Telegram может быть и игроком, и организатором (`Organizer` в БД).

---

## Мульти-спорт

У пользователя: **`User`** (демография `gender`, `ageBand`; `levelTag` для волейбольного игрового потока), **`UserSportProfile`** по каждому выбранному виду, **`MatchingProfile` + `MatchingSchedule`** с составным ключом **`(userId, sport)`** для предпочтений подбора и расписания (волейбол и теннис раздельно). Поле **`activeSport`** — последний активный вид для UI (значения Prisma `SportKind`: `volleyball` | `tennis`).

| Аспект | Волейбол | Большой теннис |
|--------|----------|----------------|
| Уровень в игровом потоке | `User.levelTag` + `UserSportProfile.volleyballSkillTag` | `MatchingProfile.playLevel` / `playLevelCode` |
| Расписание и предпочтения | `MatchingProfile` / `MatchingSchedule` с `sport = volleyball` | то же с `sport = tennis` |
| Игры `/newgame`, `/games` | основной сценарий | домен игр общий; подбор по теннису — в развитии |

## Матрица возможностей

| Возможность | Общее | Волейбол | Большой теннис |

| `/start`, upsert пользователя | да | да | да |

## Границы MVP и риски

- **Волейбол:** наиболее проработанная цепочка до оплат и напоминаний.
- **Теннис:** данные подбора сохраняются; автоматический поиск игр по профилю — **в разработке** (кнопка «Искать игры» может оставаться заглушкой).
