## 🎯 Основные понятия

### **VBallAgregator**
**Термин:** VBallAgregator  
**Определение:** Telegram-бот для автоматизации организации волейбольных игр, который помогает игрокам находить подходящие игры, а организаторам — управлять процессом набора участников, отслеживанием оплат и координацией проведения игр.  
**Английский эквивалент:** Volleyball Game Aggregator Bot

### **Организатор игры**
**Термин:** Организатор (Game Organizer)  
**Определение:** Пользователь системы, который создает волейбольные игры, устанавливает параметры (дата, время, уровень, площадка, вместимость, цена) и управляет процессом записи участников.  
**Альтернативные названия:** Администратор игры, Ведущий

### **Игрок**
**Термин:** Игрок (Player)  
**Определение:** Пользователь системы, который записывается на волейбольные игры, отмечает оплату участия и получает уведомления о предстоящих играх.  
**Альтернативные названия:** Участник, Спортсмен

### **Игра**
**Термин:** Игра (Game)  
**Определение:** Волейбольное мероприятие, созданное организатором с определенными параметрами: дата и время проведения, уровень игры, площадка, количество участников, стоимость участия.  
**Синонимы:** Матч, Турнир, Сессия

## 👥 Роли пользователей

### **Игрок (Player)**
**Роль:** Участник волейбольных игр  
**Возможности:**
- Регистрация в системе с выбором уровня
- Поиск и просмотр доступных игр
- Запись на игры соответствующего уровня
- Отмена записи с уведомлением организатора
- Отметка факта оплаты участия
- Получение уведомлений о предстоящих играх
- Просмотр истории участия в играх

### **Организатор (Organizer)**
**Роль:** Создатель и управляющий волейбольными играми  
**Возможности:**
- Регистрация в системе с указанием контактных данных
- Создание новых игр с полным набором параметров
- Управление записью участников (подтверждение/отклонение)
- Мониторинг статуса оплат участников
- Управление настройками игры (закрытие/открытие записи)
- Просмотр статистики по проведенным играм

## 🏐 Игровые термины

### **Уровень игры**
**Термин:** Level Tag / Уровень  
**Определение:** Характеристика игры, определяющая требуемый уровень мастерства участников.  
**Значения:**
- **Новичок (Beginner)** - для начинающих игроков
- **Любитель (Amateur)** - для игроков с базовыми навыками
- **Опытный (Advanced)** - для подготовленных игроков  
- **Профи (Professional)** - для высококвалифицированных игроков

### **Вместимость игры**
**Термин:** Capacity / Вместимость  
**Определение:** Максимальное количество игроков, которые могут участвовать в игре. Обычно составляет 12-18 человек для стандартной волейбольной площадки.

### **Площадка**
**Термин:** Venue / Площадка  
**Определение:** Место проведения волейбольной игры (спортивный зал, стадион, открытая площадка).

### **Цена участия**
**Термин:** Price / Стоимость  
**Определение:** Денежная сумма, которую игрок должен оплатить за участие в игре. Может быть фиксированной или зависеть от дополнительных услуг.

## 🔧 Технические термины

### **Telegram Bot API**
**Определение:** Программный интерфейс Telegram для создания ботов, позволяющий отправлять и получать сообщения, обрабатывать команды и callback-запросы.

### **Webhook**
**Определение:** Механизм автоматической передачи уведомлений от Telegram к серверу приложения при поступлении новых сообщений.

### **Inline Keyboard**
**Определение:** Клавиатура с кнопками, встроенными в сообщение Telegram, используемая для интерактивного взаимодействия с пользователем.

### **Callback Query**
**Определение:** Запрос, отправляемый при нажатии пользователем на inline-кнопку, содержащий информацию о выбранном действии.

### **Correlation ID**
**Определение:** Уникальный идентификатор, присваиваемый каждой операции для отслеживания выполнения запроса в логах системы.

## 📊 Статусы и состояния

### **Статус игры**
**Game Status** - Текущее состояние игры  
**Значения:**
- **Открыта (Open)** - запись на игру доступна
- **Закрыта (Closed)** - запись на игру прекращена  
- **Отменена (Cancelled)** - игра отменена организатором

### **Статус регистрации**
**Registration Status** - Состояние записи игрока на игру  
**Значения:**
- **Подтверждена (Confirmed)** - игрок официально записан на игру
- **В листе ожидания (Waitlisted)** - игрок в очереди на участие
- **Отменена (Cancelled)** - регистрация отменена игроком или организатором

### **Статус оплаты**
**Payment Status** - Состояние оплаты участия в игре  
**Значения:**
- **Не оплачено (Unpaid)** - игрок не отметил оплату
- **Оплачено (Paid)** - игрок подтвердил факт оплаты

## 💬 Команды и интерфейс

### **Системные команды**
**Slash Commands** - Команды, начинающиеся со слеша (/), доступные через Telegram интерфейс

| Команда | Описание | Доступность |
|---------|----------|-------------|
| `/start` | Начало работы с ботом и регистрация | Все пользователи |
| `/games` | Просмотр списка доступных игр | Зарегистрированные |
| `/newgame` | Создание новой игры | Только организаторы |
| `/join <id>` | Запись на конкретную игру | Только игроки |
| `/leave <id>` | Отмена записи на игру | Только участники |
| `/my` | Просмотр личных игр | Все пользователи |
| `/pay <id>` | Отметка оплаты участия | Только участники |
| `/help` | Справка по использованию бота | Все пользователи |

### **Inline-кнопки**
**Inline Buttons** - Интерактивные кнопки в сообщениях бота
- **Записаться** - кнопка записи на игру
- **Отменить** - кнопка отмены регистрации  
- **Оплатил** - кнопка отметки оплаты
- **Подтвердить** - кнопка подтверждения игрока организатором
- **Отклонить** - кнопка отклонения заявки

### **Callback actions**
**Callback Actions** - Действия, выполняемые при нажатии на inline-кнопки
- `join_game_*` - запись на игру
- `leave_game_*` - отмена записи на игру
- `pay_game_*` - отметка оплаты
- `confirm_player_*` - подтверждение игрока
- `reject_player_*` - отклонение игрока

## 🔄 Бизнес-процессы

### **Регистрация пользователя**
**User Registration** - Процесс первичной регистрации в системе  
**Этапы:**
1. Инициализация командой `/start`
2. Выбор роли (Игрок/Организатор)
3. Для игроков: выбор уровня мастерства
4. Для организаторов: создание профиля
5. Выбор предпочтительных организаторов (для игроков)
6. Завершение регистрации

### **Создание игры**
**Game Creation** - Процесс создания новой волейбольной игры  
**Этапы:**
1. Инициализация командой `/newgame`
2. Выбор даты проведения
3. Выбор времени начала
4. Выбор уровня игры
5. Выбор площадки
6. Установка вместимости
7. Указание стоимости участия
8. Подтверждение создания

### **Запись на игру**
**Game Registration** - Процесс записи игрока на конкретную игру  
**Этапы:**
1. Просмотр списка доступных игр
2. Выбор подходящей игры
3. Нажатие кнопки "Записаться"
4. Проверка условий записи
5. Принятие в игру (при наличии мест) или добавление в лист ожидания
6. Уведомление игрока о результате

### **Управление листом ожидания**
**Waitlist Management** - Процесс автоматического управления очередью на участие в игре  
**Принципы:**
- Игроки записываются в порядке подачи заявок
- При освобождении места первый в очереди автоматически переводится в статус "Подтверждена"
- Система автоматически уведомляет игрока о подтверждении участия

### **Система оплат**
**Payment System** - Процесс отслеживания и управления оплатами участия  
**Принципы:**
- Окно оплаты открывается с началом игры
- Игрок самостоятельно отмечает факт оплаты
- Организатор получает уведомления об оплатах
- Система автоматически напоминает неоплатившим игрокам

### **Система уведомлений**
**Notification System** - Автоматическая система информирования пользователей  
**Типы уведомлений:**
- **Игровые напоминания** - за 24 часа, за 2 часа, в начале игры
- **Платежные уведомления** - об открытии окна оплаты, напоминания о неоплате
- **Системные уведомления** - подтверждение из листа ожидания, изменения статуса игры

## 📈 Технические метрики

### **Время отклика**
**Response Time** - Время обработки команды пользователя  
**Типы:**
- Время обработки команды (command processing time)
- Время загрузки списка игр (games list load time)
- Время выполнения операции записи (join operation time)

### **Пропускная способность**
**Throughput** - Количество обрабатываемых запросов в единицу времени  
**Измерения:**
- Команд в секунду (commands per second)
- Операций записи в минуту (joins per minute)
- Созданных игр в час (games created per hour)

### **Доступность**
**Availability** - Процент времени, когда система функционирует корректно  
**Показатели:**
- Uptime percentage - процент доступности
- Mean Time Between Failures (MTBF) - среднее время между сбоями
- Mean Time To Recovery (MTTR) - среднее время восстановления
