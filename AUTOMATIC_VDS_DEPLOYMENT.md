# 🤖 Автоматическое развертывание VBallAgregator на VDS

## 📋 Что нужно знать

**ДА, проект развернется автоматически!** 

Скрипт `scripts/vds-setup.sh` выполнит все за вас:
- Установит Docker и Docker Compose
- Создаст все необходимые директории
- Настроит базовую конфигурацию
- Подготовит скрипты управления

## 🚀 Пошаговые действия

### Шаг 1: Подключение к VDS
```bash
ssh root@45.143.95.171
# Пароль: oTbG41y5Qq
```

### Шаг 2: Клонирование проекта
```bash
# Переход в домашнюю директорию
cd /root

# Клонирование репозитория (замените URL на ваш)
git clone https://github.com/your-username/VBallAgregator.git
cd VBallAgregator
```

### Шаг 3: Запуск автоустановки
```bash
# Сделать скрипт исполняемым
chmod +x scripts/vds-setup.sh

# Запустить автоматическую установку
./scripts/vds-setup.sh
```

### Шаг 4: Настройка переменных окружения
```bash
# Отредактировать production конфигурацию
nano .env.prod
```

**Обязательно измените:**
- `TELEGRAM_BOT_TOKEN` - токен вашего бота от @BotFather
- `DATABASE_URL` - замените `CHANGE_ME_PASSWORD` на безопасный пароль
- `REDIS_PASSWORD` - замените `CHANGE_ME_REDIS_PASSWORD` на безопасный пароль

### Шаг 5: Запуск приложения
```bash
# Запуск контейнеров
./start.sh

# Выполнение миграций
docker compose -f docker-compose.prod.yml --env-file .env.prod exec app npm run prisma:migrate

# Проверка статуса
./status.sh
```

## 🔧 Получение Telegram Bot Token

1. Откройте Telegram
2. Найдите @BotFather
3. Отправьте `/newbot`
4. Следуйте инструкциям
5. Скопируйте полученный токен

## ✅ Проверка работы

После выполнения всех шагов:

1. **Бот в Telegram:** Отправьте `/start` вашему боту
2. **Health Check:** Откройте http://45.143.95.171:3000/health
3. **Логи:** Выполните `./logs.sh` для просмотра логов

## 🎯 Автоматические скрипты управления

После установки будут доступны команды:

```bash
./start.sh     # Запуск приложения
./stop.sh      # Остановка приложения  
./restart.sh   # Перезапуск приложения
./logs.sh      # Просмотр логов в реальном времени
./status.sh    # Статус всех контейнеров
./backup.sh    # Создание backup БД
./update.sh    # Обновление приложения до последней версии
```

## 🆘 Если что-то пошло не так

### Проблемы с Docker
```bash
# Перезапуск Docker
systemctl restart docker

# Проверка установки
docker --version
docker compose version
```

### Проблемы с контейнерами
```bash
# Остановка и очистка
./stop.sh
docker system prune -a

# Перезапуск
./start.sh
```

### Проблемы с БД
```bash
# Проверка подключения
docker compose -f docker-compose.prod.yml exec db psql -U vball_app -d vball_prod
```
